# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Web Lunar very seriously. If you discover a potential security vulnerability, please report it responsibly:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email your findings directly to **lucasjobtech@gmail.com** or **contato@weblunar.com.br**.
3. Include detailed steps to reproduce the issue, potential impact, and suggested remediations if known.

We will review reports promptly and take necessary actions to remediate validated vulnerabilities.
